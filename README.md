# PDFium Testing Fork

This repository is **not** the official PDFium repository.  
It is a personal testing fork used to experiment with larger changes, prototype features, and evaluate architectural ideas before upstreaming them.

The purpose of this fork is to allow broader experimentation without needing to upload multiple CLs or maintain unfinished work in upstream branches.

> Reminder: This is an experimental fork and should not be treated as an official PDFium source repository.
